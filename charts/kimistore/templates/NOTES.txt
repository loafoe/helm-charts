{{ if gt (int .Values.replicaCount) 1 }}
Scaling note: with assignment disabled the extra replicas will not take any
partitions -- every claim goes to whichever agent started first. Set
assignment.enabled=true to have partitions shared by rendezvous hash. Turning it
on against a running cluster makes the incumbent drain the partitions it no
longer wins, so expect handovers rather than a silent no-op.
{{- else }}
Scaling note: this is a single replica. Raising replicaCount without
assignment.enabled leaves the extra replicas idle.
{{- end }}
